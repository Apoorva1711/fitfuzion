# FitFuzion - Fitness Club Website

A sleek, responsive gym & fitness website inspired by Cult.fit, built with pure **HTML5**, **CSS3**, and **JavaScript**.

---

## 🚀 Features
- **Hero Section:** High-energy fitness theme with quick trial booking.
- **Workout Programs:** Visual grid displaying HIIT, Strength, Yoga, and Boxing tracks.
- **Interactive BMI Calculator:** Real-time health diagnostic tool based on WHO guidelines.
- **Side-by-Side Pricing Cards:** Balanced 3-column membership tiers (Monthly, 6-Month, Annual).
- **Interactive Modal Popup:** Instant enrollment form for users to enter details.

---

## 🛠️ Built With
- **HTML5:** Semantic structure.
- **CSS3:** Custom responsive layout, CSS grid, glassmorphism, and dark athletic theme.
- **JavaScript (ES6):** Dynamic BMI computation and popup modal DOM handling.
